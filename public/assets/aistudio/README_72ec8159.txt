RADEON FUEL CALCULATOR — ANDROID PROJECT

This is an Android Studio project for your TVS Radeon 110cc fuel calculator.
It uses a local HTML page inside an Android WebView, so the calculator works offline.

BUILD APK:
1. Install Android Studio on your computer.
2. Extract this ZIP file.
3. In Android Studio, choose Open and select the extracted RadeonFuelCalculator folder.
4. Allow Android Studio to download the required Gradle/Android SDK components.
5. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
6. When the build completes, click 'locate' in the notification.
   APK path: app/build/outputs/apk/debug/app-debug.apk
7. Transfer app-debug.apk to your Android phone and install it.
   If Android asks, allow installation from that file manager.

APP DETAILS:
- English interface
- Home branch: Hamirpur
- Bike mileage: 50 km/l
- Fuel price default: Rs 102.28/litre (editable in source if needed)
- All 20 branch distances from the supplied list
- Offline calculation

NOTE:
This ZIP is the Android Studio source project, not a compiled APK.
A compiled APK requires Android SDK + Gradle build tools, which are not installed
in the current file-generation environment.
